# Evil Cats — Asset Contract (art + audio)

This file is the contract between the asset generators in `Tools/art` / `Tools/audio`
and the Unity code that loads the results. Names, sizes and folders here are what the
game code expects. If you change a name, change the code that loads it.

All art and audio in Evil Cats is **generated by code in this repository** (original work,
no downloaded or AI-generated media). Re-running the generators reproduces every file.

---------------------------------------------------------------------------------------
## 1. Pixel-art rules

* **Scale:** 16 art pixels = 1 world unit (PPU 16). Draw at 1:1; never resample sprites.
  On a typical phone one art pixel is shown at about 1.3–1.5 dp (≈4 screen pixels), so a
  20 px rat is about 28 dp tall. Design silhouettes to read at that size.
* **Look:** crisp, deliberate pixel art. Hard edges, 1 px dark outline (`PAL['outline']`
  #140c1c) around characters and props, light from the **top-left**, 3–5 step colour
  ramps with restrained shading (a little ordered dithering is fine). No anti-aliasing
  on characters/props/UI frames. Soft alpha is allowed only for FX (glows, smoke).
* **Palette:** use `eclib.PAL` / `eclib.RAMPS`. Foundation is charcoal + midnight violet.
  Electric cyan belongs to Arc Light Cat (and his lightning). Warm gold = rewards.
  Red = danger (enemy telegraphs, low health). Elements: fire orange, frost ice-blue,
  bone ivory, ward teal/gold, gravity purple. **Backgrounds are quieter and less
  saturated than enemies and controls** (use `gw_*` / `mf_*` terrain colours).
* **View:** top-down with a slight three-quarter tilt. Characters face the camera
  (down-screen) in 3/4 view; the game flips sprites horizontally for left/right
  movement, so draw them facing **right** by default.
* **Enemy identity:** every enemy of the Golden Collar Order wears a small **gold collar
  or gold badge** — a unifying motif that separates foes from the cat clan.
* **No text inside images** (except the store feature graphic). Interface text is rendered
  in Unity with TextMeshPro.
* **Tone:** mischievous dark fantasy, charming villains, light cat humour.
  **No gore**: defeated enemies vanish in a puff of dust/sparks; "bleed" is stylised.
* **Determinism:** randomness only via `eclib.rng(seed)`.

## 2. Output format (atlases)

Generators call `reg.sprite(atlas, name, img, pivot, border, anchors)` and
`reg.anim(atlas, name, frames, fps, loop, pivot)`; `build_all.py` packs everything into
power-of-two PNG atlases in `EvilCats/Assets/_EvilCats/Art/Resources/ECArt/`:

* `<atlas>.png` — RGBA atlas (transparent background).
* `<atlas>_flash.png` — only for atlases registered with `flash=True`: white silhouettes
  with the identical layout, used for hit flashes.
* `<atlas>_atlas.json` — metadata:
  ```json
  { "atlas":"enemies", "texture":"enemies.png", "flashTexture":"enemies_flash.png",
    "width":1024, "height":512, "ppu":16, "coordinateOrigin":"top-left",
    "sprites": { "enemy/rat_raider/walk/0": {"x":2,"y":2,"w":20,"h":20,
                  "pivot":[0.5,0.1], "border":[l,b,r,t], "anchors":{"hero":[0,12]}} },
    "anims":   { "enemy/rat_raider/walk": {"frames":["enemy/rat_raider/walk/0", ...],
                  "fps":8, "loop":true} } }
  ```
  `x,y` are measured from the atlas **top-left**. `pivot` is normalised from the sprite's
  **bottom-left** (Unity convention). `border` (9-slice) is `[left,bottom,right,top]` px.
  `anchors` are pixel offsets from the pivot with **+y up**.
* Animation frames of one clip must all have the **same frame size and pivot**.
* Characters' pivot is at the **feet** (usually `(0.5, 0.1)` or where the feet are).

Atlas list and owners:

| Atlas | flash | Contents |
|---|---|---|
| `hero` | no | Arc Light Cat (all clips, 4 skins) |
| `stations` | no | 6 station modules × 3 visual tiers |
| `enemies` | **yes** | 8 enemy types + elite variants |
| `bosses` | **yes** | 3 bosses |
| `citadel` | no | Nine-Lives Citadel + overlays |
| `env_gravewood`, `env_moonfall` | no | ground textures, path stamps, props |
| `fx` | no | effects, projectiles, indicators |
| `ui` | no | 9-slice frames, bars, buttons, logo emblem |
| `icons` | no | 16×16 UI icons, 24×24 perk icons, 16×16 enemy icons, 32×32 module icons |
| `portraits` | no | 64×64 portraits (hero, bosses, station operators), 32×32 avatars |

## 3. Required sprites (names are exact)

`<i>` = frame index from 0. Frame counts are minimums; more frames are fine.

### 3.1 Arc Light Cat — atlas `hero`
Design (must be identical in every asset): charcoal-black fur, **silver facial markings**
(muzzle/brow), **luminous cyan eyes**, a **lightning-bolt forehead mark** (cyan), **dark
violet mantle/cape**, a **small angular silver crown**, a **curved tail with faint cyan
electrical arcs**, a **staff topped with a suspended cyan crystal** (floating above a
forked silver head). Proud, theatrical villain posture. Frame **40×40**, pivot (0.5, 0.1).
Readable at phone size: big head, clear ears, bright eyes, crystal as a colour anchor.

| Anim name | frames | fps | loop | notes |

### 3.5 Citadel — atlas `citadel`
The **Nine-Lives Citadel**, seen from a high top-down angle so enemies all around it stay
visible. Round stone fortress, footprint circle ≈ 70 px diameter (radius 2.2 world units),
**low** walls (8–10 px visible face on the south side), a **cat-faced gate** on the south
wall (arch shaped like a cat head: ear points, two glowing cyan eye-windows), **paw-print

three **station turrets**: `crown` (north, tallest slim spire at the back), `middle` (east
bastion), `base` (south gatehouse above the gate). Crown and Base must not look adjacent;
Middle sits between them on the wall ring.

## 4. Audio

Output: `EvilCats/Assets/_EvilCats/Audio/Resources/ECAudio/music/<id>.ogg` and
`.../sfx/<id>.ogg`, plus `.../audio_manifest.json`:
```json
{ "music": { "menu": {"file":"music/menu", "loop":true, "bpm":100, "volume":0.8, "lengthSec":64.0} },
  "sfx":   { "arc_bolt": {"files":["sfx/arc_bolt_0","sfx/arc_bolt_1"], "volume":0.7,
             "pitchVar":0.05, "maxVoices":4, "cooldownMs":40, "category":"combat"} } }
```
`file(s)` are Resources paths without extension. OGG Vorbis 44.1 kHz; music stereo,
SFX mono. Music loops must be seamless. Peaks ≤ −1 dBFS; no clipping.

Music ids: `menu`, `gravewood`, `moonfall`, `boss`, `victory` (jingle, no loop),
`defeat` (jingle, no loop), `story` (opening scene, 18–22 s, no loop).
Style: playful menace — plucked strings, light percussion, low choir-like pads,
occasional magical bells/celesta accents.

SFX ids: `ui_click`, `ui_back`, `ui_denied`, `ui_toggle`, `purchase`, `reward`,
